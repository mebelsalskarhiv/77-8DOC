# 🚀 Как отправить проект на GitHub

## Быстрый старт

1. **Откройте PowerShell в папке проекта**
   - Shift + Правая кнопка мыши в папке проекта
   - Выберите "Открыть окно PowerShell здесь" или "Открыть в Terminal"

2. **Запустите скрипт**
   ```powershell
   .\push-to-github.ps1
   ```

3. **Следуйте инструкциям на экране**
   - Скрипт проверит Git и GitHub CLI
   - Откроется браузер для авторизации (если нужно)
   - Введите имя репозитория
   - Код будет отправлен на GitHub

## Что делает скрипт?

✅ Проверяет установку Git  
✅ Устанавливает GitHub CLI (если нужно)  
✅ Авторизует вас через браузер  
✅ Создает .gitignore (если нет)  
✅ Инициализирует git репозиторий  
✅ Делает commit  
✅ Создает репозиторий на GitHub  
✅ Отправляет код на GitHub  

## Первый запуск

При первом запуске:

1. Скрипт установит GitHub CLI (если не установлен)
2. Откроется браузер с GitHub
3. Войдите в свой аккаунт GitHub
4. Разрешите доступ GitHub CLI
5. Вернитесь в PowerShell и продолжите

## Параметры скрипта

```powershell
# Указать имя репозитория заранее
.\push-to-github.ps1 -RepoName "my-project"

# Указать описание
.\push-to-github.ps1 -RepoName "my-project" -RepoDescription "Мой проект"

# Создать приватный репозиторий
.\push-to-github.ps1 -Private
```

## Если что-то пошло не так

### ❌ Ошибка: "Невозможно выполнить скрипт"

Разрешите выполнение скриптов PowerShell:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### ❌ Git не установлен

Скачайте и установите: https://git-scm.com/download/win

### ❌ Не открывается браузер для авторизации

Выполните вручную:
```powershell
gh auth login --web
```

### ❌ Репозиторий уже существует

Скрипт спросит, хотите ли вы использовать существующий репозиторий.

## Использование в других проектах

Просто скопируйте файл `push-to-github.ps1` в любую папку проекта и запустите!

## Что попадет на GitHub?

Все файлы проекта, **кроме**:
- `.env` (пароли и секреты)
- `venv/` (виртуальное окружение Python)
- `node_modules/` (зависимости Node.js)
- `__pycache__/` (кэш Python)
- `logs/` (логи)
- `.vscode/`, `.idea/` (настройки IDE)

Список исключений в файле `.gitignore`

## После отправки

Ваш проект будет доступен по адресу:
```
https://github.com/ВАШ_USERNAME/ИМЯ_РЕПОЗИТОРИЯ
```

## Обновление кода на GitHub

После изменений в проекте:

```powershell
git add .
git commit -m "Описание изменений"
git push
```

Или запустите скрипт снова - он обновит существующий репозиторий.
