# BAT-файлы для управления 77-8DOC

## Файлы

### 1. `start.bat` - Запуск приложения
Основной скрипт для запуска приложения. Выполняет:
- ✅ Проверку Python
- ✅ Создание/активацию виртуального окружения
- ✅ Установку зависимостей
- ✅ Проверку файла .env
- ✅ Проверку COM-сервера 1С 7.7
- ✅ Запуск сервера на http://localhost:8000

**Использование:**
```bash
start.bat
```

### 2. `test_connection.bat` - Проверка подключения к 1С
Проверяет подключение к базе 1С 7.7. Выполняет:
- ✅ Чтение настроек из .env
- ✅ Проверку COM-сервера
- ✅ Попытку подключения к базе
- ✅ Проверку доступа к данным

**Использование:**
```bash
test_connection.bat
```

### 3. `stop.bat` - Остановка сервера
Останавливает все процессы uvicorn/Python.

**Использование:**
```bash
stop.bat
```

## Порядок первого запуска

1. **Запустите `start.bat`**
   - Скрипт создаст виртуальное окружение
   - Установит зависимости
   - Предложит настроить .env

2. **Настройте `.env`**
   ```ini
   DB_PATH_77=\\10.121.16.87\1sbase\db2018
   DB_USER_77=Администратор
   DB_PASSWORD_77=ваш_пароль
   ```

3. **Зарегистрируйте COM-сервер** (если не зарегистрирован)
   ```bash
   # От имени администратора:
   "C:\Program Files\1Cv77\BIN\1cv7s.exe" /REGSERVER
   ```

4. **Проверьте подключение**
   ```bash
   test_connection.bat
   ```

5. **Запустите приложение**
   ```bash
   start.bat
   ```

6. **Откройте браузер**
   ```
   http://localhost:8000
   ```

## Устранение проблем

### Ошибка: Python не найден
**Решение:** Установите Python 3.11+ с https://www.python.org/downloads/

### Ошибка: COM-сервер не зарегистрирован
**Решение:** Выполните от имени администратора:
```bash
"C:\Program Files\1Cv77\BIN\1cv7s.exe" /REGSERVER
```

### Ошибка: 1С вернула отказ в Initialize()
**Возможные причины:**
1. Неверный путь к базе в .env
2. Неверный логин или пароль
3. Нет прав доступа к сетевой папке
4. База заблокирована другим пользователем

**Решение:**
1. Проверьте настройки в .env
2. Убедитесь, что можете открыть базу через обычный клиент 1С
3. Проверьте права доступа к сетевой папке

### Порт 8000 занят
**Решение:** Измените порт в .env:
```ini
PORT=8001
```

```

```

```bash
notepad logs\app.log
```

## Автозапуск (опционально)

Для автозапуска при старте Windows:
1. Создайте ярлык на `start.bat`
2. Поместите ярлык в папку автозагрузки:
   ```
   %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup
   ```

## Запуск как служба Windows (опционально)

Для запуска как службы используйте NSSM:
```bash
# Скачайте NSSM с https://nssm.cc/download
nssm install 77-8DOC "C:\путь\к\77-8DOC\venv\Scripts\python.exe" "-m uvicorn backend.main:app --host 0.0.0.0 --port 8000"
nssm set 77-8DOC AppDirectory "C:\путь\к\77-8DOC"
nssm start 77-8DOC
```
