# ✅ Чеклист развертывания на сервере

## Перед копированием

- [ ] Убедитесь, что на сервере установлен Python 3.11+
- [ ] Убедитесь, что на сервере установлена 1С 7.7
- [ ] Убедитесь, что есть доступ к базе 1С 7.7

## Копирование файлов

### Что копировать:
```
77-8DOC/
├── backend/           ✅ Копировать
├── frontend/          ✅ Копировать
├── logs/              ✅ Создастся автоматически
├── requirements.txt   ✅ Копировать
├── .env.example       ✅ Копировать
├── start.bat          ✅ Копировать
├── test_connection.bat ✅ Копировать
├── stop.bat           ✅ Копировать
├── README.md          ✅ Копировать
├── QUICKSTART.md      ✅ Копировать
├── BAT_README.md      ✅ Копировать
├── INSTALL.md         ✅ Копировать
└── venv/              ❌ НЕ копировать (создастся на сервере)
```

### Что НЕ копировать:
- `venv/` - виртуальное окружение (создастся автоматически)
- `.env` - файл с паролями (создайте на сервере)
- `logs/` - логи (создастся автоматически)
- `__pycache__/` - кэш Python

## На сервере

### 1. Регистрация COM-сервера
```bash
# От имени администратора:
"C:\Program Files\1Cv77\BIN\1cv7s.exe" /REGSERVER
```

### 2. Настройка .env
```bash
# Скопируйте .env.example в .env
copy .env.example .env

# Отредактируйте .env
notepad .env
```

Укажите:
```ini
DB_PATH_77=\\10.121.16.87\1sbase\db2018
DB_USER_77=Администратор
DB_PASSWORD_77=89119
HOST=0.0.0.0
PORT=8100
```

### 3. Проверка подключения
```bash
test_connection.bat
```

Должно быть:
```
[OK] Найден COM-сервер: V77.Application
[OK] Подключение успешно!
[OK] Создание объекта Запрос успешно
Все проверки пройдены! Приложение готово к работе.
```

### 4. Запуск
```bash
start.bat
```

### 5. Проверка в браузере
```
http://localhost:8100
```

## Проверка работоспособности

### Тест 1: Health Check
```bash
curl http://localhost:8100/api/v1/health
```
Ожидается:
```json
{"status":"ok","service":"77-8DOC","version":"1.0.0"}
```

### Тест 2: Главная страница
Откройте в браузере: `http://localhost:8100`
- [ ] Страница загрузилась
- [ ] Видна форма с фильтрами
- [ ] Есть поля для дат
- [ ] Есть выбор типа документа

### Тест 3: Загрузка документов
1. Выберите период (например, последний месяц)
2. Выберите "Реализация товаров и услуг"
3. Нажмите "Загрузить"
4. Должна появиться таблица с документами

### Тест 4: Просмотр деталей
1. Кликните на иконку 👁 в любой строке
2. Должно открыться модальное окно
3. Должна быть видна табличная часть документа

## Возможные проблемы

### ❌ Ошибка: Python не найден
```bash
# Установите Python 3.11+
https://www.python.org/downloads/
```

### ❌ Ошибка: COM-сервер не зарегистрирован
```bash
# От администратора:
"C:\Program Files\1Cv77\BIN\1cv7s.exe" /REGSERVER
```

### ❌ Ошибка: 1С вернула отказ в Initialize()
Проверьте:
- [ ] Путь к базе в .env правильный
- [ ] Логин и пароль правильные
- [ ] Есть доступ к сетевой папке
- [ ] База не заблокирована

### ❌ Ошибка: Порт 8100 занят
```ini
# В .env измените:
PORT=8101
```

### ❌ Ошибка: Не загружаются документы
Проверьте логи:
```bash
notepad logs\app.log
```

## Доступ из сети

Если нужен доступ с других компьютеров:

### 1. Узнайте IP сервера
```bash
ipconfig
```

### 2. Откройте порт в брандмауэре
```bash
# От администратора:
netsh advfirewall firewall add rule name="77-8DOC" dir=in action=allow protocol=TCP localport=8100
```

### 3. Доступ с других компьютеров
```
http://IP_СЕРВЕРА:8100
```

## Запуск как служба (опционально)

Для постоянной работы используйте NSSM:

```bash
# 1. Скачайте NSSM: https://nssm.cc/download

# 2. Установите службу:
nssm install 77-8DOC "C:\путь\к\77-8DOC\venv\Scripts\python.exe"
nssm set 77-8DOC AppParameters "-m uvicorn backend.main:app --host 0.0.0.0 --port 8100"
nssm set 77-8DOC AppDirectory "C:\путь\к\77-8DOC"
nssm set 77-8DOC DisplayName "77-8DOC - Документы 1С"
nssm set 77-8DOC Description "Веб-приложение для работы с документами 1С 7.7"
nssm set 77-8DOC Start SERVICE_AUTO_START

# 3. Запустите службу:
nssm start 77-8DOC

# 4. Проверьте статус:
nssm status 77-8DOC
```
